## 项目机制

- **每日自动更新**：`.github/workflows/daily.yml` 每天 UTC 01:00 自动运行
- **内容生成**：选题池（372 位科学家，366 天全覆盖）→ 每日挑选 → 生成卡片 → 写入 README + 归档
- **展示站自动部署**：`.github/workflows/pages.yml` 自动构建 GitHub Pages
- **质量检查**：ASCII 引号校验、格式检查集成在自动发布流程中
