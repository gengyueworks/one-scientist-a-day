# 一个没有数学学位的人，让全世界爱上了数学

## 马丁·加德纳｜10月21日诞辰

1956年，《科学美国人》编辑詹姆斯·纽曼给一个写魔术杂志稿子的自由撰稿人打了个电话。这个人没有数学学位，靠给《科罗拉多斯普林斯公报》写专栏、给魔术杂志投稿维生，口袋里几乎没有积蓄。纽曼问他：愿不愿意每月写一篇数学趣题专栏？加德纳答应了。他大概没想到，这一答应就是二十五年。

## 他用折纸和棋盘，逼出了几十篇博士论文

加德纳的专栏叫「数学游戏」，从1956年一直写到1981年，共计288期，一期未断。

他不推导公式，不写证明步骤。他会这样开场：把一张纸对折再对折，展开后的折痕数量，和什么规律有关？或者：在一个无限棋盘上，一个细胞按照简单规则生死，会发生什么？后一个问题，他在1970年10月的专栏里介绍了约翰·康威刚发明的「生命游戏」，结果读者来信把编辑部淹了，服务器时代之前的那种淹法，是一麻袋一麻袋的信封。

他的题目看起来像玩具，但数学家们发现，认真解完一道加德纳的题，往往能挖出一篇正经论文。数学家罗杰·彭罗斯就是在他的专栏里，第一次向公众介绍了彭罗斯拼图。

## 没有学位，就意味着随时可以被换掉

加德纳在俄克拉荷马州长大，1936年进入芝加哥大学，读的是哲学，不是数学。毕业后他做过服务员、当过海军，战后靠写稿子过活，稿费时有时无。

没有学位这件事，不只是一个背景注脚。在那个年代，《科学美国人》是一本严肃的科学期刊，读者里有大量专业科学家。一个哲学系毕业生来写数学，随时可能被质疑、被替换。加德纳的应对方式是：每次接到新题目，他先把自己当成一个完全不懂的读者，把所有基础问题都问一遍，再把答案写得让任何人都能读懂。

这个策略的代价是速度极慢。他写每一期专栏都要和数学家通信确认细节，有时为了一道题的表述准确性，来回修改十几稿。他的档案里保存了大量手写信件，对象包括马丁·加德纳时代几乎所有活跃的数学家。

他也付出了另一种代价：二十五年里，他几乎没有时间写他真正想写的哲学和魔术。他对伪科学和超自然现象持强烈的怀疑态度，是「神奇调查委员会」的创始成员之一，但这些工作只能挤在专栏间隙里做。

1981年，加德纳以健康原因结束了专栏。他离开之后，「数学游戏」换过几任作者，再没有形成同样的影响力。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
