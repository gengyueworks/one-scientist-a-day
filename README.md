# 他把地球拼成了一张网

## 洪堡｜9月14日诞辰

1769 年出生在柏林一个贵族家庭，亚历山大·洪堡本可以什么都不用做。哥哥威廉·洪堡后来成了普鲁士的教育大臣，创立柏林大学，是那个时代最有权力的人之一。家里给弟弟安排的路也很顺：进矿务局做官，体面、稳定、前途无量。

但他二十岁那年，在哥廷根大学听了一堂课。讲课的老师叫福斯特，三十岁出头，曾经跟着库克船长环游过世界。福斯特站在讲台上，讲他见过的南太平洋岛屿、没听过的植物、地图上找不到的地方。二十二岁的洪堡坐在台下，第一次意识到两件事：这个世界可以被一个人亲自走一遍；而且已经有人这么做了。

这堂课之后，他的人生变了方向。

## 他把自己的一切押在"走一趟"上

洪堡先辞掉了矿务局的差事，花了几年时间当矿场督察，自学矿物学、地质学、植物学、物理学。那几年他在矿井里测量地温、记录空气成分，把"一个受过教育的人"该会的东西，硬生生学成了一个科学家的全套工具箱。

1799 年，他三十岁，办成了两件当时几乎不可能的事：说服西班牙王室允许他进入南美洲殖民地考察；把自己继承的遗产大半捐了出去，换成一支探险队和一船仪器。

那艘船离开西班牙港口时，他的行李箱里装满了温度计、气压计、罗盘、显微镜。他要去的地方，当时欧洲地图上还是一片模糊。

## 五年，九千六百公里

他带着法国植物学家邦普兰在南美洲登陆，开始了五年、九千六百公里的远征。他们深入亚马逊流域，得过疟疾，遭过鳄鱼，多次在生死边缘走了一遭。他爬上 5878 米高的钦博拉索山，徒手，创下三十年内无人超越的纪录。同行的人高山反应严重，他却坚持一路测量。

但洪堡真正厉害的，不是吃苦，而是他看世界的方式。

别人登一座山，看见的是"我征服了一座山"。洪堡登山，沿途记录每一个海拔高度的温度、气压、植物种类。他第一次画出"等温线"，把地球上相同温度的地方连起来；他第一次系统描述"植被垂直带"，山顶的植物和山脚的植物为什么不一样。他在秘鲁海岸发现那股寒冷的洋流，现在叫"洪堡洋流"；他发现火山分布与地磁异常有关，顺手把地球的地磁场画出了第一张图。

他不是在收集零散的知识，他在做一件事：**把孤立的事实连成一张网**。山、海、空气、植物、岩石、磁力，在他眼里不是各管各的东西，而是一个整体在呼吸。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
