# 一个贵族公爵的儿子，把电子变成了波

## 德布罗意｜8月15日诞辰

1923年，巴黎，一个三十岁的年轻人坐在书桌前，盯着一张白纸。他不是在解题，他在想一个几乎没有人会认真对待的问题：如果光既是粒子又是波，那电子为什么不能也是？这个问题在他脑子里已经转了好几年。他把答案写成一篇论文，交给了他的导师朗之万。朗之万读完，不知道该怎么评价，把它转寄给了爱因斯坦。

## 论文差点被当成笑话扔掉

德布罗意出身法国贵族，家里有公爵头衔，他本来学的是历史。转学物理是在哥哥莫里斯的影响下，莫里斯是X射线实验专家，家里甚至有一个私人实验室。但路易·德布罗意不做实验，他做的是纯粹的理论推想。

1923年的那篇博士论文只有短短几页。他提出：任何运动的物质粒子都有对应的波长，波长等于普朗克常数除以动量。这个公式今天写在所有量子力学教材的第一章，但当时看起来像是无稽之谈。物质怎么可能是波？电子是有质量的东西，不是光。

爱因斯坦收到朗之万转来的论文后，回信说这个想法「掀开了巨大面纱的一角」。就是这句话，让巴黎大学的评审委员会勉强通过了这篇论文。如果没有爱因斯坦背书，德布罗意很可能连博士学位都拿不到。

## 实验用三年时间给了他答案

论文通过是1924年。真正的验证来自三年后。

1927年，美国贝尔实验室的戴维森和革末在做电子散射实验时，意外发现电子打在镍晶体上会产生衍射图样，和X射线的衍射图样一模一样。衍射是波才有的现象。他们把数据和德布罗意的公式一对，完全吻合。同年，英国的G·P·汤姆逊也独立做出了同样的实验。

德布罗意在巴黎看到这些实验结果的时候，他的假说已经从一个「奇怪的想法」变成了可测量、可重复的物理事实。1929年，他获得诺贝尔物理学奖，是历史上极少数凭借博士论文就拿到诺贝尔奖的人。

但这里有一个代价很少被提起：他的理论被薛定谔、海森堡、玻尔这些人发展成了完整的量子力学体系，而德布罗意本人在这个过程里逐渐被边缘化。他后来提出「导波理论」，试图给量子力学加上一个更直观的物理图像，但主流物理学界不接受，哥本哈根诠释才是那个年代的正统。他在自己开创的领域里，成了一个异见者。

他在法兰西学院执教数十年，写了大量著作，坚持自己对量子力学的理解，但那条路始终没有走通。他活到了九十四岁，1987年去世，看着量子力学被应用到半导体、激光、核磁共振，却没有看到导波理论被平反。

一个人提出了改变物理学的问题，却在后来的争论里输掉了。这大概是比被忽视更难受的处境。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
