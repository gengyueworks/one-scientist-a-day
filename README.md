# 他用一根扭丝，把地球放上了天平

## 卡文迪许｜10月10日诞辰

1797年的某个深夜，英格兰克拉彭的一栋私宅里，一个老人趴在窗外，用望远镜盯着屋内一根细细的银色扭丝。他不能进去，因为他的脚步会带来震动，震动会毁掉整个实验。他就这样，在寒风里，等那根丝停止颤抖。

## 他把自己锁在实验室外面，只为不打扰地球的重量

约翰·米歇尔设计了这套装置，但没活着看到它完成。卡文迪许接手了这套仪器，并在1797年到1798年间，独自在一间专门搭建的小屋里完成了全部测量。

装置的核心是一根悬挂的扭丝，两端各挂一个铅球。他把两个更大的铅球靠近小铅球，大球的引力会让扭丝微微转动。转动的角度极小，小到必须用望远镜从屋外读数，任何人走进屋内都会引入干扰。

他做了17组测量，历时将近一年。每次调整，都要等扭丝重新静止，有时要等上好几个小时。他一个人，反复读数，反复记录。

## 一个不爱说话的人，算出了牛顿没能算出的数

卡文迪许极度回避人群。有记录说，他在皇家学会的聚会上，如果有陌生人走过来跟他搭话，他会直接转身走掉。他的管家接到命令，不得在走廊里与他对视。他把与女仆的沟通全部改成书面便条，只是为了不必开口说话。

这样一个人，却在1798年发表了那篇论文，把牛顿万有引力定律里那个悬空了一百多年的常数G，第一次用实验填了进去。他没有直接说自己测出了G，他说他测出了地球的密度。但那是同一件事。

他的结果是：地球的平均密度约为水的5.48倍。换算成今天的数值，相当于引力常数G约为6.74×10⁻¹¹立方米每千克每平方秒。现代测量值是6.674×10⁻¹¹，他的误差不到1%。

## 他死后，那笔钱才开始说话

卡文迪许去世时留下了约175万英镑的遗产，是当时英格兰最富有的人之一。他把大量财产捐给了科学机构，但他活着的时候，几乎没人知道他做了多少研究。

他的手稿在他死后被束之高阁，直到1879年，麦克斯韦整理出版了他的电学研究笔记，学界才发现，卡文迪许早在18世纪就独立得出了欧姆定律、库仑定律的结论，只是从未发表。

他不在乎发表。他做实验，记录结果，然后把笔记塞进抽屉。他的同时代人不知道他发现了什么，他本人似乎也不特别在意这件事。

剑桥大学后来用他家族的名字命名了那座著名的物理实验室。那是1874年的事，距离他去世已经过去了64年。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
