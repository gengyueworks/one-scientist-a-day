# 他们第一次让人在刀下睡着

## 麻醉手术｜10月16日事件

1846年10月16日，波士顿麻省总医院的手术剧场里，阶梯座位上挤满了医生和学生。他们来看的不是手术本身，而是一个牙医的承诺：人可以在毫无知觉的情况下被切开，然后活着醒来。这个承诺在当时听起来像是把戏。

## 那个牙医把自己的名声押了进去

威廉·莫顿（William T. G. Morton）在台上等待的时候，已经没有退路了。

他在此之前做过无数次私下试验。他用乙醚让自己的狗失去意识，让牙科椅上的病人在不知痛的情况下拔掉牙齿。他知道这东西有用，但在一座挤满怀疑者的手术剧场里公开演示，是另一回事。

主刀医生约翰·沃伦（John Collins Warren）已经等得不耐烦，冷冷说了一句话，大意是：你的魔术师在哪里？

莫顿迟到了，因为他在赶制一套新的吸入装置，直到最后一刻才赶到。他让病人爱德华·阿博特（Edward Gilbert Abbott）吸入乙醚蒸气，几分钟后，阿博特沉沉睡去。沃伦拿起手术刀，在他颈部切开，切除了一个血管瘤。阿博特没有挣扎，没有喊叫。

手术结束后，阿博特醒来，说感觉像是皮肤被划了一下。沃伦转向观众，说出了那句后来被反复引用的话：「先生们，这不是骗局。」

## 胜利之后，他用余生去争那份荣誉，什么都没争到

问题从手术成功的那一刻就开始了。

莫顿想把乙醚的配方申请专利，他甚至给这种气体起了个商业名字，试图掩盖它的真实成分。化学家查尔斯·杰克逊（Charles T. Jackson）跳出来说，是他最先告诉莫顿乙醚可以用于麻醉的，功劳应该归他。与此同时，另一位牙医克劳福德·朗（Crawford W. Long）拿出了他早在1842年就用乙醚做手术的记录，说他才是第一人。

三个人争了几十年。美国国会曾经讨论过给发现者颁发奖金，最后什么都没发，因为没人能裁定谁是真正的第一。

莫顿把大量时间和金钱花在了游说和诉讼上。他的牙科诊所荒废了，财务状况越来越糟。1868年，他在纽约街头突然发病，死的时候49岁，几乎身无分文。

他的墓碑上刻着一段话，是他的朋友们写的，大意是：他发现并向世界证明了吸入麻醉剂可以消除手术的疼痛，在他之前，手术是一种折磨，在他之后，科学征服了痛苦。

但争议没有随着他的死亡结束。直到今天，医学史界对「第一个使用麻醉的人」仍然没有完全统一的说法。

## 那一天被留下来，是因为有人选择了公开

克劳福德·朗的手术发生在1842年，比莫顿早四年，记录也是真实的。但他没有发表，没有公开演示，只是在乡村诊所里悄悄用了几次，然后等了好几年才写成论文。

10月16日之所以成为「乙醚日」，后来又被称为「世界麻醉日」，不是因为莫顿第一个想到了这件事，而是因为他第一个站在一屋子怀疑者面前，把它做给所有人看。

公开，本身就是一种选择。而这个选择让他赢得了历史，却输掉了生活。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
