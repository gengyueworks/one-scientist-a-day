# 那条消息只发出去两个字母，然后系统就崩了

## 互联网诞生｜10月29日诞辰

1969年10月29日，晚上10点半，加州大学洛杉矶分校的一间机房里，一个22岁的研究生查理·克莱恩（Charley Kline）坐在一台SDS Sigma 7主机前，准备向五百公里外的斯坦福研究院发送一条消息。消息内容很简单：「LOGIN」。他一个字母一个字母地敲，敲了「L」，打电话确认对方收到；敲了「O」，再确认。然后他敲下「G」，整个系统崩溃了。

斯坦福那边只收到了「LO」。

这就是互联网的第一句话。不是什么宣言，不是什么历史性演讲，是一个意外的崩溃，留下了两个字母。

## 这台机器要连接的，不只是两台电脑

在克莱恩坐下来敲键盘之前，这件事已经准备了将近十年。

1960年代初，美国国防部高级研究计划局（ARPA）开始认真考虑一个问题：如果苏联的核弹打掉了某一个通信节点，整个军事指挥网络会不会因此瘫痪？传统的电话网络是中心化的，一旦核心被摧毁，通信就断了。他们需要一种分布式的网络，没有单一的致命节点。

1962年，麻省理工学院的约瑟夫·利克莱德（J.C.R. Licklider）写了一系列备忘录，提出了「星际计算机网络」的构想。他设想全球的计算机彼此相连，任何人都能从任何节点访问数据和程序。这个想法在当时听起来像科幻小说。计算机在那个年代是庞然大物，一台要占满整个房间，而且每台机器使用的语言都不一样，根本没法直接对话。

真正让网络变得可能的，是一个叫「分组交换」的概念。1965年，英国物理学家唐纳德·戴维斯（Donald Davies）和美国的保罗·巴兰（Paul Baran）几乎同时独立提出了这个想法：把数据切成小包，每个包自己找路，到了目的地再重新拼起来。这样就算网络中某些节点被炸掉，数据包可以绕道走。

这个思路后来成了整个互联网的底层逻辑。

## 崩溃一个小时后，他们重启，成功了

当晚系统崩溃后，克莱恩和斯坦福那边的工程师花了将近一个小时排查问题。晚上11点，他们重新建立连接，这一次「LOGIN」完整发送过去了。

ARPANET正式通了。

参与这个项目的工程师们大多数没有意识到自己在做什么。负责整个ARPANET设计的鲍勃·卡恩（Bob Kahn）和温顿·瑟夫（Vint Cerf）在1970年代继续完善协议，1974年他们发表论文，提出TCP/IP协议，这才真正解决了不同网络之间如何互相通信的问题。

代价是真实的。整个1970年代，参与这个项目的研究人员过的是一种高度封闭的生活，项目经费来自军方，研究成果不能随意公开，很多人根本不知道自己的工作会走向何方。利克莱德本人在1990年去世，距离万维网公开发布还有一年。他没有等到普通人用上互联网的那一天。

1969年到1972年，ARPANET只有四个节点：UCLA、斯坦福研究院、加州大学圣塔芭芭拉分校、犹他大学。四台机器，连接它们的线路租金昂贵，传输速度是50Kbps，发一封电子邮件要等好几分钟。

今天全球接入互联网的设备超过150亿台。

那晚的「LO」，是个意外，也是个开始。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
