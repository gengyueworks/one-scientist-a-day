# 宇宙可能是个左撇子

## 杨振宁｜10月1日诞辰

1956 年，物理学界面前摆着一桩怪案。实验里出现两种介子，θ 和 τ，自旋一样，质量一样，电荷一样，怎么看都是同一个粒子照镜子的样子。可它们的衰变方式，一个像往左拐，一个像往右拐，完全对不上。

这桩矛盾让物理学家们寝食难安，一群人被这件事卡了三十年。没人愿意承认：同一件事物照出的两个镜像，居然会做出不一样的事。

## 三十年没人敢碰的对称

因为宇称守恒，在当时的物理学里，分量跟能量守恒、动量守恒、电荷守恒平起平坐。它的意思是：大自然不分左右，把一套物理实验整个翻成镜像，应该得到一模一样的结果。这几乎是「显然」的常识，是写在教科书底层的底牌。

可 θ 和 τ 这两只「老鼠」，除了左右键调了个方向，其余一模一样，动起来却南辕北辙。所有人都看见了矛盾，但所有人都在给矛盾找补，没人敢去掀那张牌桌。

## 敢掀牌桌的两个年轻人

1956 年，杨振宁和李政道动手了。他们提出：宇称守恒也许只是看起来普遍，在弱相互作用里，它可能根本不成立。他们还贴心地在论文里写好了怎么用实验验证。

学界一片哗然。要知道，宇称守恒在教科书里躺了几十年，无数实验为它背书，敢公开质疑它，等于把自己摆在整个物理界的对面。费曼觉得想法有意思，说可以试试，但掏出五十美元打赌宇称守不住这关；泡利更直接，说他可不相信上帝是个左撇子。

结果，半年后，吴健雄用实验把这个「左撇子」钉死了。论文发表第二年，诺贝尔物理学奖就落到杨振宁和李政道头上。从发表到拿奖只隔一年，这在诺奖史上从来没有过。而自诺贝尔奖设立超过半个世纪以来，华人在物理奖上的长期缺席，也从这一年开始结束。

## 另一颗被忽略的炸弹

但真正让杨振宁站上物理学顶峰的，可能不是这次风光。1954 年，他和米尔斯一起发表杨-米尔斯规范理论，当年因为算不下去，没什么人当回事。谁能想到，它后来成了量子电动力学的骨架，一路长成了整个标准模型的基石。论分量，它不在宇称不守恒之下。

## 一张牌桌，两个人散场

可惜的是，两位合作十余年的搭档，没能把这份荣耀分享到底。论文的排名、功劳的归属，早就悄悄在两人之间划开裂缝，拿了奖之后，干脆互不往来，形同陌路。

外人很难说清谁对谁错，只是免不了感叹：原来科学家在追求真理的时候，也是会追名逐利的。他们推翻了物理学的左右对称，却没守住自己之间的那份对称。

参考：PanSci《科学史上的今天》〈杨振宁生日〉（本地素材：source_texts/10-01-杨振宁.txt）

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
