# 那一天，城市里的灯光第一次由铀点亮

## 核电厂商业运行｜10月17日事件

1954年10月17日，苏联奥布宁斯克，一座外表朴素得像工厂仓库的建筑里，工程师们盯着仪表盘，等待一个数字稳定下来。反应堆功率：5兆瓦。这点电量放在今天，连一个小型购物中心都撑不住。但这是人类第一次把铀裂变产生的热，变成送进电网的电。外面的居民不知道发生了什么，灯还是那盏灯，亮度没有任何变化。

## 从炸弹到电网，苏联工程师走了九年

1945年广岛的蘑菇云让全世界知道了裂变的威力，但把同样的能量用来烧水、驱动涡轮，是一件完全不同的事。炸弹要的是瞬间失控，电站要的是永远不失控。

苏联物理学家库尔恰托夫带领的团队从1945年开始研究反应堆，他们要解决的问题是：怎么让链式反应慢下来、稳下来，而不是快到爆炸。他们选择了石墨作为中子减速剂，用普通水冷却，把整个系统压缩进一个可以连续运行的结构里。这个选择后来被称为RBMK型反应堆的原型，但1954年的奥布宁斯克版本，比切尔诺贝利那台要小得多，也谨慎得多。

整个建造过程在严格保密中进行。参与项目的工程师不能对家人提起自己在做什么，图纸分散保管，没有任何一个人能看到全貌。这种保密的代价是：出了问题，很难快速找到原因，因为知道完整系统的人太少了。

## 5兆瓦，一个刻意被压低的数字

奥布宁斯克核电站的设计功率是5兆瓦电功率，这个数字在当时其实是被刻意保守设定的。工程师们不确定长期运行会出现什么问题，所以宁可把功率压低，先跑起来，再慢慢观察。

电站从1954年6月开始并网测试，到10月17日正式宣布商业运行，中间四个月的时间里，操作员们轮班守在控制台，每隔几小时记录一次数据，观察中子通量有没有异常波动，冷却水温度有没有偏离预期。有几次出现了意外的功率波动，团队紧急停堆检查，最后发现是燃料棒局部过热导致的形变。他们换掉了那批燃料棒，重新启动。

这座电站一直运行到1959年，随后进行了多次升级改造，最终在2002年正式退役，服役将近半个世纪。

## 它证明了可能，也埋下了一个问题

奥布宁斯克之后，英国、美国、法国相继建起自己的商业核电站，全球核电装机容量在1960至1970年代急速攀升。到2020年代，全球约有440座核反应堆在运行，提供了全球约10%的电力。

但奥布宁斯克真正留下的遗产是一个还没有完全解决的问题：核废料放在哪里。1954年的工程师们知道乏燃料会产生高强度辐射，他们把它暂时储存在电站附近的水池里，等待「以后」的人想出办法。

七十年过去了，「以后」还没有完全到来。全球核电站产生的高放射性废料，大多数仍然储存在临时设施里，等待一个深地质处置库的最终答案。芬兰的奥尔基卢奥托正在建造人类第一座永久核废料地下储存库，预计2025年前后开始接收废料。

1954年点亮奥布宁斯克的那批铀，分裂时释放的能量已经散进了苏联的电网。但它留下的另一部分，还在某个储存池的水下，安静地衰变，等待一个没人说得准的未来。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
