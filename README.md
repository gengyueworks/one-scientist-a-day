# 他说上帝是一个圆，圆心无处不在，圆周无处可寻

## 尼科拉斯·库萨｜8月11日事件

1450年的某个夜晚，一位枢机主教坐在书桌前，试图用数学来证明上帝的本质。他画了一个圆，然后把半径越拉越长，长到无穷大。他盯着那条消失在想象中的弧线，忽然意识到：当圆无限大，它的弧就变成了直线。极大等于极小。有限触碰了无限。

这个人是尼科拉斯·库萨，1401年生于德意志摩泽尔河边的库斯小镇。他不是现代意义上的科学家，却在科学还没有从神学里分娩出来之前，用神学的语言说出了几件后来科学必须面对的事。

## 一个教士，却先于哥白尼说地球不是宇宙中心

库萨在1440年写成《论有学识的无知》，书名本身就是一个悖论。他在书里提出：宇宙没有中心，或者说，任何一点都可以是中心。地球不是固定不动的，它也在运动。

这比哥白尼的《天球运行论》早了整整103年。

他不是靠望远镜或者数学推算得出这个结论的，他靠的是哲学推理：如果上帝是无限的，那宇宙也应该是无限的；无限的空间不可能有一个特权中心。这个逻辑链条放在今天看起来像神学，但结论却和后来的天文学撞了个正着。

他还猜测，其他星球上可能有居民，只是那些居民未必和人类一样。这个想法在1440年的欧洲，是可以被烧死的那种。他没有被烧死，因为他是枢机主教，教会保护他，也因为他足够聪明，把这些话包裹在对上帝荣耀的赞美里。

## 他的代价是永远活在两个世界的夹缝里

库萨一生都在两条轨道上同时奔跑，而且两条都跑得极苦。

作为教会人士，他深度卷入15世纪教廷最激烈的权力斗争。他曾经支持「公会议至上」，主张教皇权力应受主教会议约束，为此花了多年时间在各地奔走谈判。后来他转向，支持教皇权威，被昔日盟友骂作叛徒。1450年他被任命为布里克森主教，去管辖蒂罗尔地区，结果和当地世俗领主西吉斯蒙德公爵打了将近十年的官司，一度被驱逐出教区，只能在罗马遥领职务。

作为思想者，他的处境同样尴尬。他的宇宙观太超前，没有人真正接住他扔出来的问题。同时代的人读他的书，大多把他当作一个修辞华丽的神学家，而不是一个在谈论宇宙结构的人。布鲁诺后来读了他，把那个无限宇宙的想法发展下去，最终在1600年被烧死在罗马鲜花广场。库萨的种子，结出了别人的果，也结出了别人的火。

1464年8月11日，库萨在意大利托迪去世，年约63岁。他的心脏按照遗嘱留在了故乡库斯的圣尼古拉医院，那是他自己出资建造的。身体运回罗马，葬在他亲手修缮的圣彼得镣铐教堂。一个人死后被分成两半，放在两个地方，这件事本身像极了他的一生。

他最重要的贡献或许不是任何一个具体结论，而是他示范了一种思维方式：承认人类的认知永远有边界，但边界本身值得被精确地丈量。他管这叫「有学识的无知」，意思是，知道自己不知道什么，是一种更高级的知道。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
