# 那张纸上出现了字，他哭了

## 复印机｜10月22日事件

1938年10月22日，纽约阿斯托里亚区一间借来的厨房里，切斯特·卡尔森和他的助手奥托·科内伊把一块锌板涂上硫磺，用手帕摩擦，再把一片写有「10-22-38 ASTORIA」的玻璃片压上去，打开强光照射，然后撒上石松子粉。粉末落在锌板上，显出了那几个字母。卡尔森把一张蜡纸贴上去，揭开——字迹转移了。世界上第一张静电复印件就这样出现在一间没有窗户的厨房里，旁边还有昨晚的油烟味。

## 专利到手，没有人要它

卡尔森拿到专利是1942年。接下来的六年，他带着这项发明去敲门，被关门。

IBM拒绝了他。通用电气拒绝了他。RCA拒绝了他。美国无线电公司拒绝了他。他一共被二十多家公司和机构拒绝，包括美国国家发明局。理由基本一致：谁需要这个？打字机已经够用了，复写纸也能复制文件，这个用硫磺和粉末搞出来的东西，看起来更像魔术表演，不像工业产品。

卡尔森当时在一家专利事务所做律师，白天帮别人申请专利，晚上回家研究自己的发明。他有关节炎，手指在冬天会肿痛，但他还是在厨房里一遍遍重复那个实验。他不是天才少年，他是一个三十岁出头、攒了点积蓄、不知道这条路走不走得通的普通工程师。

## 哈洛伊德公司赌了一把，赌赢了

1944年，一家叫哈洛伊德的小公司注意到卡尔森的专利。这家公司在纽约罗切斯特卖感光纸，生意一般，正在找出路。他们签下了授权协议，把这项技术命名为「Xerography」，词根来自希腊语的「干」和「书写」。

研发花了整整十四年。哈洛伊德在1959年推出第一台商用复印机Xerox 914，重达392公斤，每分钟能复印7张纸。机器太容易过热，公司随机附赠了一个小灭火器，说明书里认真写明了使用方法。

就是这台笨重、会冒烟的机器，在上市第一年就让哈洛伊德的营收从3200万美元跳到6000万美元。这家公司后来改名为施乐。

卡尔森从专利授权里拿到了分成。他后来把大部分财富捐了出去，捐给大学、捐给慈善机构，低调到去世后许多人才知道他有多少钱。他在1968年死于心脏病，死前还在安排最后一批捐款。

那块1938年的锌板，他一直留着。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
