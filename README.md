# 那个肾脏已经彻底罢工的男人，活下来了

## 洗肾成功｜9月11日事件

1945年9月11日，荷兰坎彭（Kampen）的一间临时实验室里，一台用香肠肠衣、洗衣机滚筒和橙汁罐拼凑起来的机器，正在嗡嗡作响。躺在旁边的是一个尿毒症晚期的病人，血液从他手臂的静脉流出，绕过那台怪机器，再流回去。没有人知道接下来会发生什么。发明这台机器的医生威廉·科尔夫（Willem Kolff）也不知道。

## 前六次，病人全死了

科尔夫开始做透析实验是在1943年，彼时荷兰正处于德国占领之下。他在赞丹（Zwolle）的一家小医院工作，物资极度匮乏，他用的管子是从飞机零件商那里弄来的赛璐玢肠衣，转鼓是铝制的，驱动靠手摇。

从1943年到1945年，他一共治疗了16名病人，前15名全部死亡。不是机器不转，是这些病人来的时候已经太晚，肾脏完全衰竭，身体里堆积的毒素早就超过了机器能清除的极限。每一次失败，科尔夫都在记录本上写下数据，调整参数，再等下一个病人。

第16个病人是一名67岁的女性，叫索菲亚·斯霍弗滕（Sofia Schafstadt）。她因急性肾衰竭陷入昏迷，同时患有胆囊炎。1945年9月11日，科尔夫为她进行了透析，治疗持续了约11个小时，机器从她的血液里清除了大量尿素和毒素。

她醒了。

她后来又活了7年，最终因其他疾病去世，但那一天的肾衰竭，被机器拉了回来。

## 这台机器的代价，是整个战时的隐秘

科尔夫做这件事，背景并不光彩，或者说，极为复杂。

荷兰被占领期间，他所在的医院必须向德国当局汇报。他一边做实验，一边参与地下抵抗网络，帮助藏匿犹太人，伪造身份证件。他把透析机的研究藏在繁重的日常医疗工作背后，用的材料很多是通过非正式渠道获得的。

战争结束后，科尔夫没有申请任何专利。他把透析机的设计图纸免费寄给了全球各地的医院，包括波兰、英国、加拿大和美国。他的理由很简单：如果这个东西能救人，就应该让更多人用得上。

这个决定让他在商业上一无所获，但透析技术因此在1950年代迅速扩散。

## 他后来去造了人工心脏

1950年，科尔夫移居美国，加入克利夫兰医学中心（Cleveland Clinic）。他没有停在透析这件事上，而是把目光转向了整个人体的机械替代：人工心脏、人工眼、人工耳。

1982年，他的团队在犹他大学制造的人工心脏「贾维克-7」（Jarvik-7），被植入了一名叫巴尼·克拉克（Barney Clark）的牙医体内。克拉克靠这颗机械心脏又活了112天。

科尔夫本人活到了97岁，2009年去世。他在接受采访时说过，自己最大的遗憾，是没能在有生之年看到完全可植入的人工心脏真正普及。

1945年9月11日那台用香肠肠衣做的机器，是这一切的起点。一个女人在昏迷中被接上了一台从没成功过的装置，然后睁开了眼睛。科尔夫在记录本上写下数据，和前15次一样，但这一次，数字的后面跟着的是：病人存活。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
