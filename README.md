# 如果宇宙无限大，夜空为什么不是一片白光？

## 奥伯斯佯谬｜10月11日事件

1823年，德国天文学家海因里希·奥伯斯坐在书桌前，盯着一张白纸。他要写的不是新发现，而是一个困扰他很久的问题：如果宇宙无限大、星星无限多，那么无论你朝哪个方向看，视线最终都会落在某颗恒星上。整片天空应该亮如白昼。可他推开窗，外面是漆黑的夜。这说不通。

## 这个问题本来不是他第一个想到的

奥伯斯不是第一个被这个问题困住的人。开普勒在1610年就注意到了它，英国天文学家哈雷在18世纪初也写过相关文章，瑞士天文学家德谢索在1744年甚至给出了相当接近现代答案的推理。但这个问题最终挂上了奥伯斯的名字，原因很简单：他在1823年把它写得足够清晰，足够让后人反复引用。

他的推导逻辑本身是严格的。把宇宙想象成一层一层的球壳，每往外一层，星星的数量按距离平方增加，而每颗星的亮度按距离平方衰减。两者正好抵消。结论是：每一层球壳贡献的光量相同。无限多的球壳叠加，亮度应当是无限大。

奥伯斯自己给出的解释是：星际空间存在某种吸收光线的物质。这个答案错了。后来的物理学指出，如果真有这样的介质，它迟早会被加热到与恒星一样的温度，然后自己发光，问题还是没解决。

## 真正的答案藏在宇宙的年龄里

这个佯谬真正的出路，直到20世纪才变得清晰。

1929年，哈勃发现宇宙在膨胀。遥远的星系正在高速远离我们，它们发出的光被拉伸成红外线，甚至微波，人眼根本看不见。这是一部分原因。但更根本的一条是：宇宙有年龄。

宇宙大约诞生于138亿年前。光速是有限的，所以我们能看到的宇宙有一个边界，叫「可观测宇宙」，半径约465亿光年。边界之外的光还没来得及到达我们这里。宇宙存在的时间不够长，还没有足够多的光填满夜空。

换句话说，夜空是黑的，不是因为宇宙有边界，而是因为宇宙还太年轻。

这个答案在1848年就被爱伦·坡在一篇散文《我发现了》（*Eureka*）里以诗人的直觉触碰到了。他写道：背景的黑暗，是因为宇宙的深度还不足以让光填满每一个方向。物理学家们用了将近一个世纪才追上这个直觉。

## 一个问题比一个答案更有生命力

奥伯斯本人是业余天文学家，职业是医生。他白天在不来梅出诊，夜里在自家屋顶架着望远镜观测。他发现了多颗小行星，计算过彗星轨道，但这些具体的发现都没有让他的名字活到今天。

让他被记住的，是一个他自己没能解决的问题。

「奥伯斯佯谬」这四个字现在出现在每一本宇宙学教材里，作为一道入门题。它的厉害之处在于：只需要肉眼看一眼夜空，再加上几行中学数学，你就能逼出宇宙膨胀和宇宙年龄这两个20世纪最重要的宇宙学结论。

一个好问题，有时候比一百个答案更能推动科学往前走。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
