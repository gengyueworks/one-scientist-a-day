# 战壕里算出来的那个解，让宇宙出现了一个洞

## 史瓦西｜10月9日诞辰

1915年12月，卡尔·史瓦西正蹲在俄国前线的战壕里。他是德国炮兵部队的一名军官，负责计算炮弹弹道。夜里炮声停歇时，他把爱因斯坦刚发表的广义相对论论文翻出来读，然后开始在纸上演算。他用不到一个月，算出了广义相对论方程的第一个精确解。

## 爱因斯坦本人都没想到能算出精确解

爱因斯坦在1915年11月发表广义相对论时，自己也只给出了近似解。他认为这组方程太复杂，精确解几乎不可能得到。

史瓦西在战场上，针对最简单的情形，也就是一个静止的、球对称的质量体周围的时空，硬是把方程解了出来。他在1916年1月把论文寄给爱因斯坦，爱因斯坦回信说，他没想到有人能用这么简洁的形式得到精确解，并亲自在普鲁士科学院宣读了这篇论文。

这个解里藏着一个奇怪的数值，后来被称为「史瓦西半径」。把任何质量压缩到这个半径以内，时空就会弯曲到连光都跑不出来。太阳的史瓦西半径约为3公里，地球的约为9毫米。当时没人认真对待这件事，觉得那不过是数学上的奇点，现实里不会存在。

## 他只剩四个月，却还寄出了第二篇论文

史瓦西在战壕里染上了天疱疮，这是一种皮肤自身免疫疾病，在当时几乎无药可治。1916年3月，他从前线被送回国内。5月，他去世，年仅42岁。

他死前还完成了第二篇论文，处理的是均匀密度球体内部的时空解。两篇论文，前后相差不过几周，都是在他生命最后几个月里写成的。

他没能看到后来发生的事。1960年代，物理学家们重新认真对待史瓦西解，「事件视界」这个概念被正式提出，人们开始相信黑洞真的存在。2019年，事件视界望远镜拍下了第一张黑洞照片。那个边界，就是用史瓦西半径描述的那条线。

史瓦西在战壕里花了几个星期算出来的东西，人类用了一百年才真正看见它长什么样。

## 他说过

> 如你所见，尽管战争的炮火在四周肆虐，这片战场依然允许我从这些思想的国度里漫步其中，并做出这个发现。

（此为史瓦西在寄给爱因斯坦的信中所写，1916年1月）

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
