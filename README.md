# 一场宴席之后，他再也没能站起来

## 第谷·布拉赫｜10月27日事件

1601年10月13日，布拉格，一场贵族宴会正进行到高潮。第谷·布拉赫坐在长桌旁，觥筹交错，宾客喧嚣。他是皇帝鲁道夫二世的御用天文学家，是那个时代欧洲最精密的星象观测者，但那一晚，他做了一个让自己送命的选择：他没有离席去厕所。

在那个年代，贵族宴席上中途离座被视为失礼。第谷忍住了。整个晚上，他一直忍着。

回家之后，他的膀胱开始出问题，再也没有真正好转过来。十四天后，1601年10月27日，他在布拉格去世，终年54岁。死因至今仍有争议。

## 他用肉眼看见了别人看不见的东西

第谷活着的时候，望远镜还没有被发明出来。他所有的观测，全靠肉眼加上自己设计的巨型仪器完成。

他在丹麦的汶岛上建了一座叫乌兰尼堡的天文台，花了国王弗雷德里克二世约1%的国家年收入来维持运转。他在那里工作了约20年，积累了当时精度最高的行星位置数据，火星轨道的测量误差控制在约2角分以内，这个精度在前望远镜时代几乎是极限。

他记录了1572年出现在仙后座的一颗新星，观测到它从无到有、从亮到暗，历时约16个月。这直接动摇了亚里士多德「天界永恒不变」的说法，因为那颗星明显在月球轨道之外，却在变化。

他还测量了1577年的一颗彗星，发现它的轨道穿越了行星轨道，这意味着行星不可能嵌在固体水晶球壳上运转——那些球壳根本不存在。

## 他死前把数据交给了一个他不完全信任的人

第谷一生最大的遗产，不是他自己的理论，而是那批数据。

他不相信哥白尼的日心说，提出了一个折中方案：地球静止不动，太阳绕地球转，其他行星绕太阳转。这套「第谷体系」在当时有一定市场，但最终没有被历史采纳。

问题是，他手里攥着全欧洲最好的行星观测数据，却始终不愿意完整公开。他担心别人用这些数据建立比他更好的理论，抢走他的荣誉。他雇用约翰内斯·开普勒作为助手，让开普勒帮他整理火星数据，但只给看一部分。

开普勒后来回忆，第谷对数据的保密程度让合作变得极为艰难。两人关系时好时坏，摩擦不断。

第谷病倒之后，开普勒守在他床边。第谷在临死前几天反复说了一句话，开普勒记录下来的拉丁文是：「Ne frustra vixisse videar」，意思是「但愿我不曾虚度此生」。

第谷死后，开普勒设法获得了那批数据的控制权，过程并不完全光明磊落——数据的法定继承权属于第谷的家人，开普勒与他们之间为此争执多年。

但正是靠着这批数据，开普勒在1609年发表了行星运动第一、第二定律，1619年发表了第三定律。没有第谷二十年的观测积累，开普勒的计算就没有足够精确的原材料。

## 他说过

> 「但愿我不曾虚度此生。」
>
> ——第谷·布拉赫，1601年10月，临终前数日

第谷的骨骼在1901年和2010年被两次挖出来检测。2010年的分析发现他骨骼中的汞含量偏高，但研究者认为这更可能来自他自己服用的炼金术药物，而不是谋杀。他大概只是死于泌尿系统感染引发的并发症，死于一场他不愿意中途离席的宴会。

他把一生最精确的东西留了下来，却没能亲眼看见它被用来做什么。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
