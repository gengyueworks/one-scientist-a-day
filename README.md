# 那个被忽视了半个世纪的数字

## 阿伏伽德罗｜8月9日诞辰

1811年，一篇论文安静地出现在法国期刊《物理学杂志》上。作者是意大利都灵的一位律师出身的物理学教授，名叫阿梅代奥·阿伏伽德罗。他在文章里提出了一个当时几乎没有人愿意认真对待的想法：在相同温度和压力下，等体积的任何气体，含有相同数目的分子。这句话听起来平淡，却是整个现代化学的地基。没有人鼓掌。没有人回应。论文就这样沉进了学术史的泥沙里。

## 他站在两个错误之间，选择了第三条路

1811年之前，化学界有两个权威：道尔顿和盖-吕萨克。道尔顿用原子论解释物质，但他拒绝承认同种原子能结合在一起；盖-吕萨克用实验数据证明气体反应时体积成简单整数比，却解释不了为什么。两人的理论互相打架，谁也说服不了谁。

阿伏伽德罗看出了症结：只要承认气体的基本粒子不是单个原子，而是由多个原子组成的「分子」，两边的矛盾就迎刃而解。氢气不是一个氢原子，而是两个氢原子结合的分子；氧气也是。这样，一体积氢气加一体积氯气，恰好生成两体积氯化氢，数字对上了。

这个逻辑今天看来几乎是常识。但在1811年，他是在向道尔顿的权威开炮。道尔顿本人明确反对，认为同种原子之间没有结合的理由。欧洲化学界的主流选择站在道尔顿那边。

## 沉默持续了整整四十九年

阿伏伽德罗没有放弃。他在都灵大学教了将近三十年书，继续发表论文，继续完善分子假说。但欧洲大陆的化学家们开会、争论、制定原子量标准，从来没有把他的名字放进讨论中心。

1856年，阿伏伽德罗去世。他没有等到那一天。

1860年，德国卡尔斯鲁厄召开了第一届国际化学家大会。会议的核心议题，正是原子和分子的定义之争，化学界乱成一锅粥。意大利化学家坎尼扎罗在会上散发了一份小册子，系统整理了阿伏伽德罗四十九年前的假说，并用新的实验数据逐一验证。与会者当场被说服。那一年，「分子」这个概念才真正进入化学的官方语言。

阿伏伽德罗已经死了四年。

后来，科学家们用他的名字命名了那个数：每摩尔物质所含的粒子数，约为6.02×10²³。这个数字大到难以想象，一摩尔沙粒铺开可以覆盖整个地球表面数米深。它被刻进每一本化学教材，成为连接宏观世界和微观粒子的桥梁。

他用一生等来的，是身后的承认。

## 他说过

> 「我们必须承认，等体积的不同气体，在相同温度和压力下，含有相同数目的分子。」

这句话写于1811年，被忽略了将近半个世纪，然后变成了整个化学的基石。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
