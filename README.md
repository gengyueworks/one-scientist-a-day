# 天平之上，头颅之下

## 拉瓦锡｜8月26日诞辰

十八世纪的化学，还是罩着神秘与魔幻外衣的炼金术。连牛顿那样的人物都曾沉浸其中，却始终没能像他在物理里创造奇迹那样，把它变成一门清楚的科学。直到一个巴黎人出现，迷雾才被一点点拨开。

他叫拉瓦锡，后世称他「现代化学之父」。而他生命的结局，是一把落下的铡刀。

## 为了养实验室，他把自己押上赌桌

拉瓦锡生在巴黎的富裕人家。家人盼他当律师，他却常在课余研读化学、植物学、数学，毕业后也不急着执业，跑去考察矿区。二十六岁那年，他撞见一个「绝佳」的机会——税务官：只要预先垫付一笔税款给皇室，就能替皇家收税，多收的全进自己口袋，还免税。靠着这份稳定丰厚的收入，他买得起仪器，养得起一间像样的实验室，从此无后顾之忧地做学问。

他以为这是通往科学殿堂的捷径。那一天他不会想到，这纸契约日后会写成他自己的死刑判决书。

当上税务官的同年，他因研究石膏入选法国科学院院士。第二年，他把矛头对准「四元素说」的证据——「水经长时间加热会变成土」。他把实验里每一份质量的增减都称得清清楚楚，发现那些「土」根本不是水变的，而是来自装水的容器。一个流传数百年的说法，被一把天平轻轻推翻。

## 一把天平，称碎了燃素说

1772年，他向更大的庞然大物发难：燃素说。当时人们相信，物质燃烧时，会释放出藏身其中的「燃素」。拉瓦锡依然用定量的老办法，用一连串简洁的实验证明：金属燃烧后增加的重量，恰好等于空气减少的重量。没有燃素。他把参与燃烧的那种气体命名为「氧气」，算出它在空气中的比例，连「空气是单一元素」的旧观念一并推翻。他甚至指出，呼吸不过是体内的碳与氧结合，生成二氧化碳与热量——和燃烧一模一样。

靠着这些实验，他坐实了质量守恒定律，又制定出统一的化学命名规范，让散落各地的科学家第一次有了共同语言。1789年，他出版史上第一本系统化的化学教科书《化学要论》，定义了元素的概念，首次列出三十三种元素。两年后，他以科学院院士的身份，起草了公制。

## 革命的账，不认科学的功

可惜，天平能称出氧气，称不出时代的癫狂。1793年，法国大革命向皇室清算，身为税务官的拉瓦锡跟着遭殃：科学院先被勒令关闭，接着他被逮捕拘禁，半年后走上断头台。他头颅落地的次日，数学家拉格朗日叹道：「砍下这颗头颅只需一瞬间，可是即使再过一百年，只怕再也找不到这样的头脑。」一年半后，他虽获平反，人却早已不在。

他用一份聪明的契约换来了实验室，也亲手把自己的命押给了权力。化学从此成了一门精确的科学，而它的奠基人，倒在了革命最锋利的刀刃下。天平和铡刀，一样都不留情面。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
