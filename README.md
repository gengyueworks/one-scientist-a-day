# 一场官司，让美国中学生至今还在争论宇宙是怎么来的

## 创世论｜8月18日事件

1925年7月，田纳西州小镇代顿的法庭外，摆摊的人卖着猴子玩偶和柠檬水。镇上的居民把这场审判当成节日。法庭里，一个24岁的中学代课教师约翰·斯科普斯坐在被告席上，他的罪名是：在课堂上教了达尔文的进化论。这在田纳西州是违法的。

## 一部法律让「猴子审判」成了世纪笑话

田纳西州议会在1925年3月通过了《巴特勒法案》，明确禁止公立学校教师讲授「任何否认《圣经》所述人类神圣创造的理论」。美国公民自由联盟随即在报纸上登广告，征求愿意以身试法的教师。斯科普斯接受了邀请，被捕，受审。

这场审判吸引了全美记者涌入代顿，包括著名评论家孟肯。辩护律师是大名鼎鼎的克拉伦斯·达罗，检察官一方请来了三度竞选总统的威廉·詹宁斯·布莱恩。两个老人在法庭外临时搭的棚子里当众对峙，达罗逼着布莱恩承认《圣经》里的「六天创世」未必是字面意义上的六天。布莱恩五天后在代顿去世，据说死于糖尿病和疲惫。斯科普斯被判罚款100美元，后来因程序问题撤销。

《巴特勒法案》在田纳西州一直保留到1967年才废除。

## 「创世科学」换了一件外衣，官司打到了2005年

输掉舆论战之后，创世论者没有消失，他们换了策略。到1980年代，「创世科学」开始出现在教科书讨论里，主张《圣经》创世记录可以用科学方式验证。阿肯色州和路易斯安那州相继立法，要求公立学校在教进化论的同时讲授创世科学。联邦法院两度判定这违反政教分离原则，分别是1982年和1987年。

被判违宪之后，又一个变体出现了：「智慧设计论」。它不提上帝，只说生命体的复杂程度无法由随机演化解释，背后必有「智慧设计者」。2004年，宾夕法尼亚州多佛学区的教育委员会要求生物课必须介绍智慧设计论，并在课堂上放置《熊猫与人类》这本教材。11位家长联合起诉学区。

2005年12月，联邦法官约翰·琼斯三世在判决书里写了139页，结论是：智慧设计论是「创世论的变体」，在公立学校课堂推行违宪。他同时指出，参与推动这项政策的部分教育委员会成员在庭上作伪证。多佛学区为这场官司付出了超过100万美元的法律费用。

## 争论从法庭转移到教科书委员会

法庭打不赢，战场就移到教科书审定委员会。德克萨斯州的教科书采购量足以影响全美出版商的内容取舍，因此德州教育委员会的每一次投票都会被全国盯着看。2009年，委员会投票通过要求学生「分析和评估」进化论的证据，批评者认为这是为质疑进化论留了口子。

8月18日，在这场旷日持久的拉锯战里，是一个节点：1999年的这一天，堪萨斯州教育委员会投票，将进化论、宇宙大爆炸等内容从州立科学考试标准中删除。这个决定让堪萨斯州立刻成为全球媒体嘲讽的对象。两年后，委员会换届，新成员投票恢复了这些内容。再过几年，委员会又换人，争论重新开始。

这场争论没有终点。它不是科学内部的争论，而是关于「谁有权决定孩子在学校里被告知什么」的权力之争。每隔几年，它就换一个名字，穿一件新衣服，重新走进法庭或委员会会议室。

> 「智慧设计论不是科学。它无法将自身与宗教区分开来。」
> ——联邦法官约翰·琼斯三世，2005年基茨米勒诉多佛学区案判决书

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
