# 那个提着塑料袋到你家敲门的人，是世界上最伟大的数学家之一

## 爱多士｜9月20日忌日

1996年9月，华沙一场数学会议的走廊里，一个八十三岁的老人突然倒下。他随身携带的家当，装在两个半满的塑料袋里。没有公寓，没有银行账户，没有固定地址。他的财产大概值几百美元，但他一生发表的数学论文超过一千五百篇，合作者遍布二十五个国家。保罗·爱多士（Paul Erdős）就这样死在路上——对他来说，这大概是最合适的死法。

## 他把自己的地址设定成「下一班飞机」

爱多士没有家。这不是比喻，是字面意思。

他在1934年离开匈牙利去英国读博，此后再也没有真正定居过任何地方。二战期间他辗转美国各地，1954年因为拒绝配合麦卡锡时代的政治审查，被美国吊销再入境许可，在英国、以色列、欧洲各地漂了将近十年，直到1963年才重新拿到美国签证。

他的日常运作方式是：给某位数学家发一封信或打一个电话，说「我打算在你家住几天」，然后真的出现在对方门口，提着那两个塑料袋。他会在你家住上一周，每天工作十九个小时，把一个或几个问题解决掉，然后消失，去下一个人家里。

他一生的旅行费用，部分来自他自己设立的数学奖金——他把拿到的奖项奖金直接拿出来，悬赏给能解决他提出的难题的人。奖金从十美元到三千美元不等，视题目难度而定。他自己的生活开销极低，因为他根本不需要付房租。

## 五百一十二个合作者，和一个叫「爱多士数」的传染病

跟爱多士合作过的数学家，被称为爱多士数为1，总共有512人。跟这512人合作过的，爱多士数为2，大约有一万一千人。这个数字像病毒扩散一样蔓延到整个数学界，乃至物理学、计算机科学、经济学。爱因斯坦的爱多士数是2，比尔·盖茨是4。

为什么他能合作这么多人？部分原因是他真的走遍了所有人的家。但更重要的是，他有一种罕见的能力：他能看出哪个问题值得花时间，然后把它说得让你也觉得值得花时间。他会在你的客厅里，用他那口混着匈牙利腔的英语，把一个困了他几十年的组合数论问题摆在你面前，说「你来试试」。很多人就真的试了，然后发现自己解出来了一部分，然后论文就出来了。

他把上帝叫做「SF」，Supreme Fascist（最高法西斯），因为上帝总是把最好的定理藏起来不告诉人类。他把孩子叫做「epsilon」，数学里代表极小量的符号。他把死亡叫做「离开」。他的语言体系是一套完整的数学隐语，跟他相处久了，你会不自觉地开始用同一套词。

## 他付出的代价是所有「正常」的东西

爱多士的母亲陪了他很久。她在他父亲早逝后，一直是他生命里最稳定的存在。1971年，她在陪他旅行时去世，享年九十一岁。爱多士此后进入了一段极度黑暗的时期，靠安非他命撑过每一天。

一位朋友曾打赌，说如果爱多士能戒掉安非他命一个月，就给他五百美元。爱多士真的戒了。一个月后，他把五百美元收下来，然后说：「你让我意识到我不是上瘾。我只是选择用它，因为没有它，我什么都不想做。」然后他继续用了。

他没有婚姻，没有子女，没有房子，没有存款。他曾在晚年说，他只有在解题的时候，才感觉自己是活着的。

1996年9月20日，他在华沙倒下，死于心脏衰竭。他在生命最后几天里还在开会、还在证题。他的塑料袋没人知道最后去了哪里。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
