# 一只流口水的狗，照见你我不愿承认的真相

## 巴甫洛夫｜9月26日诞辰

科学史上最出名的两只宠物，是薛定谔的猫和巴甫洛夫的狗。前者是虚构的，只活在思想实验里；后者却是货真价实、活生生的一只狗，唯一的绝活，是流口水。

可名气大了也有代价。全世界都记住了这条会流口水的狗，反而没人记得，它身后那个人到底在做什么。

## 在清醒的狗身上，开一道门

巴甫洛夫原本研究的，是狗的胃液。当时人们已经知道，食物进入胃之后，会刺激胃液分泌。他好奇的是更早一步的问题：食物还没到胃，胃会不会就提前分泌了？

要观察答案，只能拿清醒的活狗做实验。巴甫洛夫用一双巧手，把狗的食道和胃各开了几条瘘管接到体外：狗咽下的食物从食道瘘管直接排出，根本进不了胃；而胃里分泌的胃液，则从胃部的瘘管流出来。实验结果证实了他的猜想——食物根本不用进胃，光是看见、闻到、尝到，胃液就已经开始分泌。他还进一步比较了不同食物让胃液分泌的快慢、多少与持续的时间。

这套严谨的消化实验，为他赢得了1904年的诺贝尔生理或医学奖。但站在领奖台上，他讲的主题却是另一件事。

## 台上领诺奖，心里念着流口水

那是他在实验室里顺手记下的一个细节：每当负责喂食的工作人员走进房间，狗就开始分泌唾液。狗分明还没看到食物，只是认出了「喂饭的人要来了」。

巴甫洛夫顺着这个细节追了下去：他在食物出现之前，先给狗视觉或听觉上的信号——图片、哨子、节拍器、音叉。这些信号本来和唾液毫无关系，可连着喂几次之后，狗被「制约」了：就算盘子里没有食物，只要信号一响，它照样口水直流。

有意思的是，后人传说里那枚著名的「铃铛」，从来就没在他的实验里出现过。他用的明明是这些更朴素的工具。

## 别急着笑狗，照照自己

别急着笑话狗笨。后来的实验证实：人同样会被制约。一声毫无来由的响声，一个不起眼的气味，就可能在我们毫无察觉的时候，勾出恐惧、厌恶之类的情绪反应。

这就是「巴甫洛夫的狗」能流传一百年的原因——那条狗用一声哨子、一张图片，轻轻戳破了「人是自己主人」的自信，也照见了一个让人不太舒服的事实：我们并不完全是自己情绪的主人。在理性、意志力、甚至自由意志够不到的地方，还藏着一片由条件反射织成的幽暗角落。狗用口水回答的问题，最后落在了每个人自己身上。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
