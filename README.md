# 一场没人听懂的演讲，改写了宇宙

## 黎曼｜9月17日诞辰

1854年，哥廷根大学，一个不到三十岁的年轻人站上讲台，做生平第一次就职演讲。台下的教授们大概不会想到，就在这一场演讲里，纵横了两千年的欧氏几何，从「绝对真理」跌成了「特殊情况」；他们更想不到，五十年后，有人会靠着这套东西，推翻牛顿的万有引力。

这个年轻人叫黎曼。他活着的时候穷困潦倒，死后却让整个物理学界都记住了他的名字。

## 从神学院里「逃」出来的数学家

黎曼的父亲是牧师，一心想让儿子继承神职。进了哥廷根大学，黎曼只能修神学与哲学——可他真正的兴趣在数学，而「数学王子」高斯，恰好就在这所学校任教。高斯一眼看出这个学生非同小可，积极鼓励他放下神学，投身数学。也许是冲着高斯的名声，父亲终于松了口。黎曼改学最爱的数学，在高斯的指导下完成论文，1851年拿到博士学位。

## 平行线，为什么会「相遇」

在他之前，俄国的罗巴切夫斯基已经质疑过平行公设，提出「过直线外一点，可以作不止一条平行线」的双曲面几何。但他仍停留在二维的观念里，试着在曲面上重建欧几里得的定理。黎曼走得更远：他革命性地引入拓扑的概念，定义了张量与曲率，造出一整套能完整描述空间的数学工具。

这套工具在物理学界沉寂了许多年，直到爱因斯坦撞上一堵墙——广义相对论需要一门能描述「被扭曲的时空」的几何，而传统语言做不到。经一位数学家朋友介绍，爱因斯坦读到了黎曼几何，这才推导出重力场方程式，完成了广义相对论，把统治了两百多年的牛顿引力拉下王座。

## 贫病交加，却留下一道百年天堑

黎曼的遗产远不止几何。数学里堆满了以他命名的名词，其中最著名的，是黎曼猜想。希尔伯特把它列为1900年提出的二十三个世纪问题之一，曾放话：若他沉睡千年后醒来，第一个要问的就是黎曼猜想有没有被证明。如今它又跻身克莱数学研究所悬赏百万美元的七大难题，一百多年过去，依然无人能解。

可这些成就，没能换来他的好日子。他长期担任没有薪水、只能向学生收费的讲师，收入微薄，生活困苦，直到三十三岁才当上有固定收入的正教授，而身体早已垮掉。不到四十岁，他因肺结核离开人世。

他生前饿着肚子把几何翻了个底朝天，身后用一个猜想，难住了全世界一百多年。命运欠他的体面，历史用另一种方式，加倍还给了他。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
