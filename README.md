# 一坨发霉的意外，改写了人类命运

## 弗莱明｜8月6日诞辰

1928年9月初，英国细菌学家弗莱明结束假期，回到伦敦圣玛丽医院的实验室。工作台角落堆着一叠培养皿，其中一只，是他离开前忘了收好的葡萄球菌培养皿。他无奈地打算清理，手却停在了半空：培养皿里本该长满葡萄球菌，唯独一团绿色霉斑的周围干干净净，像是被谁悄悄擦掉了一块。

他盯住那圈异常的空白，心里浮起一个念头：莫非这种霉菌，能杀死葡萄球菌？

## 七年，才换来这一眼

弗莱明把霉菌分离出来，反复实验后发现，它会分泌某种物质，不仅杀得死葡萄球菌，对其他多种革兰氏阳性菌也有效。他把这种分泌物命名为青霉素，也就是后来通称的盘尼西林。人类历史上第一种抗生素，就这样在一只忘收拾的培养皿里出生。

很多人说他运气好，接住了一场天降的意外。但请记住：在霉菌的孢子落进培养皿之前，弗莱明已经埋头于抗菌研究整整七年。正因为那些年磨出来的一双眼睛，他才能在一堆脏兮兮的培养皿中间，一眼认出那圈空白意味着什么。科学从来没有什么侥幸，先有七年的准备，才有资格谈那一秒钟的幸运。

## 挖到金矿，却十年搬不动

然而发现之后，是更长的冷板凳。

第二年他发表论文，却再没了下文。他的化学基础不够，提不出大量提纯青霉素的办法；手头又没有临床案例佐证疗效，医学界根本没把这篇论文当回事。到了1935年，又有一种磺胺剂被发现能杀菌，他这条线索更被挤到了角落。他明明挖到了一整座金矿，却怎么都撬不动——这大概是弗莱明一生最憋闷的几年。

直到1939年，牛津大学的病理学教授弗洛里偶然翻到他的论文，与旅居英国的德国生化学家钱恩合作，才打通了批量生产青霉素的路，并用临床实验证明了它的疗效。青霉素随即在第二次世界大战里，救回无数受伤感染的士兵。1945年，三个人共同登上诺贝尔医学奖的领奖台。

## 一语成谶的警告

功成名就的弗莱明，没有一丝得意。他反而一次次站在演讲台上提醒人们：不要轻易使用青霉素，否则会养出产生抗药性的细菌。这个警告在当时听来近乎扫兴，可几十年过去，抗生素被滥用后酿成的后果，一字一句地验证了他当年的远见。

大多数人都看得见霉斑，只有他看懂了霉斑周围那片空白。七年隐忍，换来一眼；一眼背后，是一场迟到了十一年的胜利。所谓幸运，其实长在日复一日的专注里。

## 这是什么

一个日更型科学家人物库，每天按日期推送一位科学家：

- **日期锚点**：每位科学家的文章挂在他的诞辰/忌日/重大成就日
- **原创叙事散文**：不讲百科履历，只讲关键时刻、关键选择与代价（800-1200 字）
- **重点人物长文**：牛顿、居里、爱因斯坦、图灵这类，单独写深度特写（1500-2500 字）
- **自动更新**：GitHub Actions 每天自动跑，写入 README + 归档 + 重建展示站

选题池（372 位科学家，覆盖全年 366 天）在 [`data/pool.json`](data/pool.json)。
