# 实验室里多出来的那点光

## 伦琴｜3月27日诞辰

1895 年十一月的一天，年过半百的德国物理学家伦琴，在实验室里忙到了傍晚。他做的是门老实验——阴极射线。这东西从 1869 年希托夫第一次发现它起，吵了二三十年，连它是粒子还是波都没吵出结果。

他刚做完莱纳德那套实验：把阴极射线管阳极那端的玻璃开个小窗，用铝箔封住，管子仍能维持真空；再把一张涂了荧光材料的纸板靠近铝箔窗，纸板亮了，证明射线穿过了铝箔——这支持了「阴极射线是波」的说法。伦琴如法炮制，验证无误。

然后，他换了一根管子，接上电，关了灯。

## 不该出现的荧光

就在黑暗里，他看见一、二公尺外的墙上，有一小片幽幽的荧光。

他开灯一看，发光的不是墙，是他刚刚随手放在旁边的荧光纸板。可这不合理：希托夫管是完全密封的，从来没人见过射线跑到管外来；莱纳德也证明过，阴极射线在空气里走不了几十公分就没了。伦琴索性用黑布把整根管子包起来，纸板照样发光。

那就不是阴极射线。是一种没人见过的东西。他叫不出名字，索性用数学里最常用的记号，管它叫 X。

## 六星期的执念

接下来六个星期，伦琴几乎住在实验室里。他把纸板、木头、金属一样一样横在射线和纸板之间——全挡不住，只在纸板上留下深浅不一的影子。只有铅，能把这道看不见的射线完全截断。

最让他震撼的，是某天他拿一小片铅块挡着时，纸板上竟现出了自己手骨的影像。隔着皮肉，他第一次「看见」了自己的骨头。

到年底，他把发现公之于世，附上一张照片：他的妻子戴着戒指的左手，骨架清晰可见。全世界都愣住了。

## 一发不可收拾的光

X 射线的运气，在科学史上几乎找不到第二例。法国物理学家贝克勒尔只是被震动了，想研究它，两个月后就在顺手的实验里发现了放射性，无意中替居里夫妇指了条路；爱迪生第二年就造出 X 光机，卖给医院；第一次世界大战时，居里夫人改装出 X 光巡回车，开到战场上替伤兵做诊断。

从发现到救人，中间几乎没隔几年。历史上没有任何一样科学新发现，能像 X 射线这样，在这么短的时间里造成这么大的影响，又立刻变成实用的工具。1901 年，第一届诺贝尔物理学奖颁下来，落在伦琴名下，几乎没有任何悬念。

他原本研究阴极射线，只是想做一遍前辈们的旧实验，看能不能瞧出什么端倪。那是一件再普通不过的差事——一个做了一辈子实验、年过半百的物理学家，按理说不该再撞上什么新鲜事。

可偏偏在关了灯的那一刻，墙边多出了一小块本不该有的光。
